# BIOTERP — Landing Page

Next.js 14 + Tailwind CSS landing page inspired by the BIOTERP CBD tincture site.

## Stack

- Next.js 14 (App Router)
- React 18
- Tailwind CSS 3
- TypeScript
- lucide-react icons

## Sections

1. Age verification modal (21+ gate)
2. Sticky navigation header
3. Hero with product bottle (SVG) + dual CTAs
4. Product specifications card (30ml · 6000mg CBD · 0.2% THC)
5. Manufacturing & quality (4-column grid)
6. About Sawyer Labs (Utah, USA)
7. Therapeutic benefits (5 cards)
8. Limited-time countdown
9. Product purchase section with price
10. FAQ accordion
11. Footer with newsletter signup

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```
